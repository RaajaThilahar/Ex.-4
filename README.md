### Aim: 
To write the prompt for the following prompt types and compare that with different AI tools and evaluate that using any one evaluation method (Ex. Rubrics). Zero-shot Prompting.•	Few-shot Prompting - Chain of Thought -	Persona Pattern - Reverse Prompting - Graph Prompting - Active Prompting 


### Procedure:
1.Open a Generative AI tool such as ChatGPT and select a common topic or problem for the experiment.

2.Define the objective of the experiment and decide the type of response required from the AI.

3.Prepare a Zero-shot Prompt by directly asking the AI to perform the selected task without providing any examples.

4.Prepare a Few-shot Prompt by providing two or more examples to demonstrate the expected format or style before asking the actual question.

5.Prepare a Chain-of-Thought Prompt by asking the AI to solve or explain the task in a logical, step-by-step manner.

6.Prepare a Persona Prompt by assigning a specific role to the AI, such as a teacher, researcher, programmer, or expert, and then provide the task.

7.Prepare a Reverse Prompt by asking the AI to identify the requirements of the desired output, construct an appropriate prompt, and then generate the response.

8.Prepare a Graph Prompt by representing the concepts, entities, or relationships in a structured graph-like form and asking the AI to expand or explain them.

9.Prepare an Active Prompt by allowing the AI to ask relevant questions or request additional information before generating the final response.

10.Execute each prompt separately using the same Generative AI tool and record the generated outputs.

11.Compare the outputs obtained from all seven prompting techniques based on accuracy, relevance, clarity, completeness, and overall quality.

12.Assign suitable scores to each technique based on the evaluation criteria and prepare a comparison table.

13.Analyze the results to identify which prompting technique provides the most effective response for the selected task.

14.Record the result and conclusion of the experiment based on the comparison.

A. Zero-shot Prompting:

B. Few-shot Prompting:

Give the AI a few examples before asking the actual question.

Prompt:

Example 1:
Topic: Artificial Intelligence
Explanation: Artificial Intelligence is the ability of machines to perform tasks that normally require human intelligence.

Example 2:
Topic: Deep Learning
Explanation: Deep Learning is a subset of Machine Learning that uses neural networks with multiple layers.

Now explain Machine Learning in the same style. Include its definition, types, applications, advantages, and limitations.

C. Chain-of-Thought Prompting:

Ask the AI to reason through the problem step by step.

Prompt:

E. Reverse Prompting:

Instead of directly giving the complete prompt, ask the AI to determine what information/prompt would be needed to produce the desired answer.

Prompt:

I want to learn Machine Learning as a college student. First, determine what information should be included in an ideal explanation of Machine Learning. Then create an effective prompt that can be used to generate that explanation. Finally, use that prompt to provide the answer.

F. Graph Prompting:

Represent the information as relationships between concepts.

Prompt:

Explain Machine Learning using a graph-like structure. Represent the relationships as:

Machine Learning → Types → Supervised, Unsupervised, Reinforcement
Machine Learning → Applications → Healthcare, Finance, Education
Machine Learning → Process → Data → Training → Model → Prediction

Expand these relationships and explain each concept in simple terms suitable for a college student.

Use an interactive approach where the AI asks for information/clarification before generating the final answer.
